# 📘 Advanced Java – OffHeap HashMap Project

## Задание

Реализовать **off-heap структуру данных** `OffHeapIntIntHashMap` и сравнить её эффективность с `HashMap<Integer, Integer>` с помощью **JMH-бенчмарков**.

### Основная цель

* Хранить пары `(int key, int value)` **вне кучи** (off-heap) с использованием `Unsafe` или `ByteBuffer.allocateDirect`.
* Измерить производительность (время вставки, поиска) и использование памяти.
* Сравнить с обычной `HashMap`.

---

## Требования

1. **Реализовать интерфейс `OffHeapIntIntHashMap`:**

```java
void put(int key, int value);
int get(int key);
bool containsKey(int key);
bool remove(int key);
void clear();
long size();
void free(); // освобождение off-heap памяти
```

2. **Провести тестирование через JMH-бенчмарки**:

    * Метрики:

        * `put` (вставка)
        * `get` (поиск)
        * потребление памяти
    * Объемы данных:

        * `100`, `1000`, `10000`, `1000000` элементов

3. **Построить графики**:

    * Время вставки vs количество элементов
    * Время поиска vs количество элементов
    * Использование памяти vs количество элементов

4. **Сделать выводы**:

    * Где off-heap быстрее
    * Где медленнее или потребляет больше памяти

---

## Сборка проекта

Проект использует **Gradle Kotlin DSL** и **Java 21**.

```bash
./gradlew build
```

---

## Запуск JMH

```bash
./gradlew jmh
```

Результаты будут сохранены в:

```
build/reports/jmh/jmh-result.json
```
