# Домашнее задание: Реализация Int-Int HashMap на массивах

## Цель

* Научиться реализовывать разные стратегии разрешения коллизий в хеш-таблицах.
* Сравнить производительность и использование памяти своих реализаций с `java.util.HashMap`.
* Понять влияние структуры данных на работу JVM и GC.

---

## Задание

### 1. Интерфейс `IntIntMap`

Все реализации должны соответствовать интерфейсу:

```java
public interface IntIntMap {
    void put(int key, int value);
    int get(int key);
    boolean containsKey(int key);
    void remove(int key);
    int size();
}
```

### 2. Реализации на массивах

Реализуйте следующие алгоритмы на основе массивов `int[] keys` и `int[] values`:

1. **`IntIntHashMapChaining`** — коллизии через цепочки (linked list).
2. **`IntIntHashMapLinearProbing`** — линейное пробирование.
3. **`IntIntHashMapRobinHood`** — Robin Hood hashing.

> Все реализации должны работать только на массивах, без объектов-обёрток и off-heap.

### 3. Бенчмарки с JMH

Создайте JMH-бенчмарки для сравнения:

* всех своих реализаций
* `java.util.HashMap<Integer, Integer>`

**Метрики:**

* Время вставки (`put`)
* Время поиска (`get`)
* Использование heap-памяти

**Размеры данных:**

* 100 элементов
* 1,000 элементов
* 10,000 элементов
* 100,000 элементов
* 1,000,000 элементов

**Heap-память:**

* Используйте `-XX:+PrintGCDetails -Xmx512m` или JMH GC-профайлер (`@BenchmarkMode(Mode.SampleTime) + -prof gc`) для оценки использования памяти.

### 4. Построение графиков

По результатам JMH:

* Построить графики времени вставки vs количество элементов
* Построить графики времени поиска vs количество элементов
* Построить графики потребления памяти vs количество элементов

### 5. Отчёт

* Включить все графики.
* Сделать выводы:

    * Какая стратегия быстрее?
    * Какая компактнее по памяти?
    * Как разные реализации влияют на heap и работу GC?
